# Archivio Collezioni

App per tenere traccia delle collezioni (carte, Funko, fumetti, gadget) organizzate per brand. Funziona dal browser del telefono, anche offline. I dati restano sul dispositivo di chi la usa.

Apri: https://mascia91.github.io/archivio-collezioni/

## Archivi usati

- Carte Pokémon: [TCGdex](https://tcgdex.dev) (prezzi Cardmarket)
- Carte Magic: [Scryfall](https://scryfall.com)
- Libri: [Open Library](https://openlibrary.org)
- Funko: `funko.json`, ridotto da [funko-pop-data](https://github.com/kennymkchan/funko-pop-data) di Kenny Chan (licenza MIT), foto hobbyDB
